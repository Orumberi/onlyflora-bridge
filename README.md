# OnlyFlora Bridge

Закрытый MCP-мост между ChatGPT/Codex и OnlyFlora в Webasyst Shop-Script и «Сайт».

Он позволяет после входа **на стороне Webasyst**:

- читать дерево категорий и карточки товаров;
- искать товары до создания дублей;
- создавать и редактировать категории;
- создавать товары/услуги с признаком `Цена от`;
- добавлять товар в категорию и создавать SKU;
- загружать проверенные изображения товаров (JPEG, PNG, GIF или WebP до 5 МБ);
- получать утверждённую структуру раздела «Благоустройство».
- просматривать домены и дерево страниц приложения «Сайт»;
- читать, создавать и редактировать страницы, их HTML, заголовки и параметры.

Удаляющих инструментов в мосте нет. Новые товары и страницы по умолчанию создаются неопубликованными. Перед обновлением страницы мост сначала проверяет, что она существует.

Для доступа к страницам Webasyst OAuth запрашивает приложения `shop,site`. После обновления с версии 0.2 соединение OnlyFlora Bridge в ChatGPT необходимо переподключить один раз.

## Важное ограничение

Стандартный OAuth API Webasyst не предоставляет методы для чтения и записи файлов темы дизайна и загрузки штатной миниатюры категории. Поэтому мост загружает изображения товаров, а миниатюры категорий добавляются в интерфейсе Shop-Script. Клон темы `OnlyTest` умеет выводить эти штатные миниатюры без дополнительного плагина.

## Развёртывание в Timeweb Cloud

1. Создайте Backend-приложение из этого GitHub-репозитория.
2. Среда: Express, Node.js 24.
3. Команда сборки: `npm ci`.
4. Команда запуска: `npm start`.
5. Проверка состояния: `/health`.
6. Добавьте секретные переменные из `.env.example`.
7. Для `AUTH_SECRET` используйте не менее 32 случайных символов и храните значение только в секретах Timeweb.
8. После выдачи постоянного HTTPS-домена укажите его в `APP_BASE_URL` и перезапустите приложение.

После запуска MCP endpoint будет доступен по адресу:

```text
https://ВАШ-ДОМЕН/mcp
```

При подключении ChatGPT откроет стандартный вход Webasyst. Логин и пароль вводятся только на странице `onlyflora.ru`, мост их не получает и не хранит. Выданный Webasyst access token помещается в зашифрованный токен соединения и не записывается в репозиторий или журналы.

## Локальная проверка

```bash
cp .env.example .env
npm ci
npm test
npm start
```

В режиме разработки без `APP_BASE_URL` используется `http://localhost:3000`. В production необходим постоянный HTTPS URL.
