# OnlyFlora Android 1.0.0

Android-приложение OnlyFlora для публикации в RuStore и Google Play.

- Application ID: `ru.onlyflora.mobileapp`
- Минимальная версия Android: 7.0 (API 24)
- Target/compile SDK: API 36
- Основной адрес: `https://app.onlyflora.ru/`
- Форматы релиза: подписанные APK и AAB

Приложение поддерживает JavaScript, cookies, системную кнопку «Назад», выбор
файла/фотографии и отдельный экран повтора при сетевой ошибке. Внешние ссылки
открываются в браузере, а внутри приложения разрешён только официальный домен.

Инструкция по ключу подписи и сборке находится в `STORE_RELEASE.md`.
