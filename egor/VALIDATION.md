# Проверка первой версии — 21.09.2026

## Выполнено

- Проверены реальные товары через подключённый OnlyFlora Bridge:
  карточка 18544 и восемь результатов поиска «Смарагд».
- Для SKU 21264: 25 растений 60–80 см / C3 / Садовый Лабиринт дают 31 875 ₽.
- Для SKU 60831: 25 растений 110 см / WRB / Гарден Маркет дают 191 250 ₽.
- Автотесты проверяют несовпадение контейнера, формы и сорта, объединение
  остатков, дубли между строками и карточками, неизвестный остаток, скрытые товары,
  отсутствие закупочных цен в ответе, пагинацию, неполный поиск, защиту API,
  отказ распознавания на неполном ответе провайдера.
- Локальные HTTP-тесты проходят полный путь от POST списка до результата
  с каталогом из реальной сохранённой фикстуры. Это не онлайн-запрос хостинга.
- Команды проверки: `npm test`, `npm run check`,
  `node --check egor/public/app.js`, `node --check egor/public/widget.js`.

## Ещё не выполнено

- Реальное распознавание фото: отсутствуют серверные ключ и выбранная модель.
- Сквозной онлайн-подбор: отсутствует отдельный серверный токен чтения каталога.
- Деплой в Timeweb: доступ для изменения его настроек не предоставлен.
- Запись в Only Test: установленный Bridge 0.4 не имеет инструментов записи темы.
- Проверка мобильного вида в браузере после установки.

Основная витрина и установленный клон этим кодом не изменены.
Версия не объявляется готовой к публичному запуску.
